# Register File on FPGA (DE0-CV)

🌐 [Português](README.md) · [English](README.en.md)

Interactive on-board test (DE0-CV) for the RV32I register file ($32 \times 32$ bits), operated directly via switches (`SW`), buttons (`KEY`, `FPGA_RESET_N`), LEDs (`LEDR`), and 7-segment displays (`HEX`).

[![Register File Demo (Video in Portuguese)](https://img.youtube.com/vi/6z75OKjMnCE/0.jpg)](https://youtu.be/6z75OKjMnCE?si=i_e1n5RB_PhHB0rD)

## 1. Operation

1. The register-file clock is a single pulse generated by an edge detector from `FPGA_RESET_N` (active-low); each press of the button produces 1 clock cycle and commits the write configured on the switches on the rising edge.
2. Register `x0` stays hardwired to zero ($x_0 = 0$); reading address `0` returns `0` and writes to address `0` are ignored.
3. Read addresses A and B and write address C are selected by the switches in the range $0..3$ (with the upper bits fixed to zero in the test top level).

## 2. Input and Output Mapping

### 2.1. Inputs

| Pin | Signal / Function |
| :--- | :--- |
| `SW[9]` | Write enable on the next clock pulse (`1` enables write) |
| `SW[8:6]` | 3-bit write datum, zero-extended to 32 bits |
| `SW[5:4]` | Write address C (2 least significant bits, zero-extended to 5 bits) |
| `SW[3:2]` | Read address B (2 least significant bits) |
| `SW[1:0]` | Read address A (2 least significant bits) |
| `KEY[0]` | Asynchronous register-file reset (active-low, inverted before the clear input) |
| `FPGA_RESET_N` | Clock-step button (active-low, generates 1 pulse via edge detector) |

### 2.2. Outputs

| Pin | Displayed Signal |
| :--- | :--- |
| `HEX0` | Read address A |
| `HEX1` | Read address B |
| `HEX2` | Lower nibble (`[3:0]`) of the datum read from port A |
| `HEX3` | Lower nibble (`[3:0]`) of the datum read from port B |
| `HEX4` | Write nibble (`'0' & SW[8:6]`) |
| `HEX5` | Write address C |
| `LEDR[0]` | State of `SW[9]` (write enable) |
| `LEDR[1]` | State of `not KEY[0]` (active clear) |
| `LEDR[2]` | State of `not FPGA_RESET_N` (step button pressed) |
| `LEDR[3]` | 50 MHz board clock (`CLOCK_50`, visual reference) |
